# Security policy

UthyAgent is an early alpha, not a supported security product. Do not use it with credentials, financial accounts, or sensitive production data.

Security-sensitive reports should not be posted publicly with exploit details. Use the repository's private vulnerability-reporting path if GitHub makes it available. If it is not enabled, open a general issue asking for a private contact method without including exploit details. Do not send API keys, personal screenshots, or task databases with a report.

The documented limitations and data flows are in [`docs/security.md`](docs/security.md). The application currently lacks a general Wayland backend, sandboxing, Telegram, and MCP support; do not infer protections from absent features.
